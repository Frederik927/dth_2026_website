# Advantages of open source software


## Advantages 


Looking beyond the cost savings, the flexible nature and adaptability of open source software provides communities with abundant possibilities. Furthermore, open source software also adds an extra layer of security and transparency. Among others, the source code is disclosed meaning it can be controlled by people for security issues and quality, providing a more secure framework than proprietary software. This collaborative working fosters a collective approach to problem-solving, prompting more resilient projects in the end. As anyone can share and modify an open source code, projects can also persist even though the original developers are not part of it anymore or the financial situation is unsustainable. Thus, one of the major advantages of open source software is that it prompts development to meet the needs of users rather than revenue. So, even though it takes effort to build and maintain open source software, it provides programmers and non-professionals with invaluable opportunities for collaboration, discussion and feedback. This way, open source software creates strong communities with the capacity to affect people and companies’ everyday life.
